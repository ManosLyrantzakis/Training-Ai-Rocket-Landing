Deep Q-Learning for Lunar Landing

This project implements a classic Deep Q-Network (DQN) agent to solve the LunarLander-v3 environment.

The AI agent learns how to land a spacecraft safely using Reinforcement Learning techniques.

🔥 Features
Fully connected neural network
Experience Replay
Target Network updates
Soft update interpolation
Epsilon decay exploration
🛠 Technologies Used
Python
PyTorch
Gymnasium
NumPy
🎯 Environment
LunarLander-v3
📈 Training Goals

The agent learns how to:

Control spacecraft movement
Reduce crash probability
Optimize landing efficiency
Maximize cumulative rewards
